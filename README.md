# Plant Growth Simulation — 2D → 3D

A continuous exploration of a **2D plant simulator developed in Python**, evolving toward **3D rendering and plant growth control with GLSL**.
Branching patterns and control of the Space Colonization Algorithm is based on previous worked developed in the [GrowSpace](https://github.com/YasmeenVH/growspace) project.

This repository documents ongoing experiments in procedural plant architecture, growth simulation, and GPU-based approaches to representing and interacting with plant-environment dynamics.

This was developed during research funded by Abundant Intelligences.
